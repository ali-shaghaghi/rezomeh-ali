### اسکریپت‌های کمکی (Console)
```js
// اسکرول افقی؟ باید false باشد
document.documentElement.scrollWidth > window.innerWidth

// عناصر بیرون‌زده از صفحه (اولویت‌بندی یافته‌ها)
[...document.querySelectorAll('*')].filter(e =>
  e.getBoundingClientRect().right > innerWidth + 1 ||
  e.getBoundingClientRect().left < -1).map(e => e.className).slice(0,10)

// شمار عناصر لمس‌پذیری زیر 40px
[...document.querySelectorAll('a,button,input,select')].filter(e => {
  const r = e.getBoundingClientRect(); return r.height && r.height < 40; }).length
```

### سرور و چک سریع رندر
- سرور (پس‌زمینه): `php artisan serve --host=127.0.0.1 --port=8000`
- چک رندر CLI: `curl -s http://127.0.0.1:8000/<مسیر> | grep -c "عنصر موردنظر"` — نسخه fa با `/locale/fa` و en با `/locale/en`.

### ستون‌های جدا برای هر صفحه
- **fa** با `/locale/fa` — جهت RTL.
- **en** با `/locale/en` — جهت LTR (بررسی معکوس‌شدن آیکون‌ها و اتصالات `start/end`).

☐ حالت لمسی: هیچ محتوای hover-only بدون دسترسی لمسی نماند (کارت‌ها با tap باز شوند).
☐ بدون اسکرول افقی در هیچ ویوپورتی (اسکریپت بخش ۰).
☐ دکمه back مرورگر: URL و محتوا هم‌خوان بمانند.

## ۲. صفحات عمومی

### صفحه اصلی `/` ☑ (تأیید قبلی: منو، اسکرول به بخش‌ها، ترجمه‌ها، بنر)
☐ هیرو: کارت شیشه‌ای `max-w-[320px]` در 360px داخل صفحه.
☐ بخش‌های مهارت/تجربه/پروژه/محصول/مشاوره/بلاگ: کارت‌ها تک‌ستونه، تصاویر کشیده‌نشده.

☐ شمارنده‌های آمار (`data-count`) در موبایل انیمیت شوند و متن نهایی خالی نماند (رفع قبلی با `repairAfterMorph`).

### محصولات `/products` ☑ (تأیید قبلی: سرچ موبایل استک تمام‌عرض)
☐ ردیف فیلتر (سرچ + ۳ سلکت + حذف فیلتر): موبایل تک‌ستونه تمام‌عرض، بدون overlap.
☐ تایپ سرچ (debounce): بدون پرش صفحه، اسکرول حفظ شود.
☐ گرید در 390px حداکثر ۲ ستونه؛ نام/قیمت truncate.
☐ صفحه‌بندی: دکمه‌ها ≥ 40px، wrap شوند.

### جزئیات محصول `/products/{slug}` ☑ (بازبینی کد)
☐ گالری: تصویر اصلی + بندانگشتی‌های `grid-cols-4 h-16` داخل صفحه.
☐ برچسب تخفیف (`left-4 top-4`) بیرون نزند.

### سبد و چک‌اوت `/cart` و مرحله ۱–۴
☐ **صورت‌حساب (step3): جدول ۴ ستونه داخل `overflow-hidden` در 360px بریده می‌شود یا نه؟** (نقطه ضعف شناخته‌شده — بخش ۶، ردیف ۲)

### ۴.۱ صفحه AI `/admin/ai` (جدید — تست شود)
☐ هشدار «هوش مصنوعی فعال نیست» وقتی کلید API تنظیم نیست؛ لینک به `admin.settings.group('ai')` کار کند.
☐ **تولید مقاله** (`ai.article-writer`): فرم `sm:grid-cols-2` و `sm:grid-cols-3` در موبایل تک‌ستونه؛ دکمه «تولید مقاله» تمام‌عرض؛ حالت loading («در حال تولید...») و غیرفعال‌شدن دکمه؛ خروجی JSON در `<pre dir="ltr">` با `max-h-64` اسکرول داخلی — کد بلوک LTR داخل صفحه RTL نشکند؛ دکمه «ذخیره به‌عنوان پیش‌نویس» → مقاله در بلاگ ساخته شود.
☐ **دستیار پروژه** (`ai.project-assistant`): لیست درخواست‌های pending تک‌ستونه (`sm:grid-cols-2`)؛ دکمه «تحلیل» هر کارت ≥ 40px؛ خروجی تحلیل (`whitespace-pre-line`) متن بلند بدون سرریز.
☐ **تلگرام** (`ai.telegram-publisher`): فیلدهای Bot Token / Chat ID با `dir="ltr"` و `font-mono` در موبایل تمام‌عرض؛ وضعیت «متصل»؛ دکمه‌های ذخیره/تست در یک ردیف یا wrap؛ بخش انتشار (`telegram-publish`): دو سلکت تک‌ستونه، دکمه «تولید کپشن» و «انتشار» wrap شوند، textarea کپشن قابل ویرایش.
☐ آیتم سایدبار ادمین به `admin.ai.index` (در `AdminPanel master`) هایلایت شود.
