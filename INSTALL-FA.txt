================================================================
 راهنمای نصب روی هاست cPanel — پروژه Laravel
 تهیه‌شده برای: هاست خریداری‌شده پارس‌پک (سایر هاست‌های cPanel هم همین است)
================================================================

بسته شامل:
  - کل پروژه به‌همراه vendor و public/build (آماده اجرا)
  - database.sql  (دیتابیس کامل — ۶۷ جدول با داده‌ها)
  - .env          (تنظیمات تولیدی — باید ویرایش شود)
  - install.php   (اسکریپت نصب یک‌بارمصرف)

----------------------------------------------------------------
 گام ۱ — آپلود و استخراج
----------------------------------------------------------------
1. وارد cPanel شوید → File Manager.
2. به مسیر اصلی هاست (home شما، نه public_html) بروید.
3. فایل rezomeh-cpanel.tar.gz را در همین مسیر آپلود کنید
   (داخل هیچ پوشه دیگری نبرید — خود آرشیو پوشه rezomeh دارد).
4. راست‌کلیک روی فایل → Extract → استخراج کنید.
   خروجی: پوشه rezomeh ساخته می‌شود.
   (روش جایگزین با Terminal:
      cd ~ && tar -xzf rezomeh-cpanel.tar.gz)

----------------------------------------------------------------
 گام ۲ — ریشه دامنه (Document Root) را روی public تنظیم کنید
----------------------------------------------------------------
سایت Laravel باید از پوشه public اجرا شود، نه ریشه پروژه.

1. cPanel → بخش Domains (یا Aliases).
2. دامنه خود را پیدا کنید → Manage/Manage Document Root.
3. مسیر را روی زیر تنظیم کنید:
      /home/USERNAME/rezomeh/public
   (USERNAME همان نام کاربری cPanel شماست)

اگر امکان تغییر document root نبود (روی بعضی هاست‌ها قفل است):
   محتوای درون پوشه public را به public_html منتقل کنید و بقیه
   پوشه‌ها (app, vendor, ...) را یک سطح بالاتر از public_html
   بگذارید؛ یعنی ساختار:
      ~/app  ~/vendor  ~/public/...  ← داخل public_html

----------------------------------------------------------------
 گام ۳ — ساخت دیتابیس
----------------------------------------------------------------
1. cPanel → MySQL® Databases.
2. یک دیتابیس بسازید (مثلاً rezomeh) — نام کامل (prefixed) را یادداشت کنید.
3. یک کاربر بسازید (نام + رمز — هر دو را یادداشت کنید).
4. کاربر را با ALL PRIVILEGES به دیتابیس اضافه کنید.

----------------------------------------------------------------
 گام ۴ — ایمپورت دیتابیس
----------------------------------------------------------------
1. cPanel → phpMyAdmin.
2. دیتابیس ساخته‌شده را از ستون سمت چپ انتخاب کنید.
3. تب Import → فایل database.sql (از پوشه rezomeh) را انتخاب کنید
   → جدول‌ها: همان پیش‌فرض → Go.
4. باید ۶۷ جدول ساخته شود.

----------------------------------------------------------------
 گام ۵ — تنظیم فایل .env
----------------------------------------------------------------
فایل ~/rezomeh/.env را با File Manager (Edit) باز کنید و موارد
زیر را عوض کید (مقادیر YOUR_ از قبل گذاشته شده‌اند):

  DB_DATABASE = نام کامل دیتابیس از گام ۳
  DB_USERNAME = نام کاربر دیتابیس
  DB_PASSWORD = رمز کاربر دیتابیس
  APP_URL     = https://your-domain.com   (دامنه واقعی با https)

اگر ورود با Google/GitHub را فعال می‌کنید:
  GOOGLE_REDIRECT_URL و GITHUB_REDIRECT_URL را هم به آدرس
  https://your-domain.com/... تغییر دهید.

ذخیره کنید (Ctrl+S).

----------------------------------------------------------------
 گام ۶ — اجرای نصب (Terminal)
----------------------------------------------------------------
1. cPanel → Terminal (اگر فعال نبود، از پشتیبانی پارس‌پک بخواهید
   ترمینال را فعال کند).
2. اجرا کنید:

     cd ~/rezomeh
     php install.php

   اسکریپت: تنظیمات را چک می‌کند، storage:link می‌سازد و کش‌ها
   را warmup می‌کند. اگر دیتابیس را ایمپورت نکردید:
     php install.php --migrate

3. اگر خطای WARN درباره APP_URL داد، .env را کامل‌تر کنید و
   دوباره اجرا کنید.

----------------------------------------------------------------
 گام ۷ — گواهینامه SSL
----------------------------------------------------------------
1. cPanel → SSL/TLS Status → دامنه را تیک بزنید → Run AutoSSL.
   (یا از همان صفحه Domains، گزینه Force HTTPS Redirect را روشن کنید)
2. بعد از فعال شدن SSL، در صورت نیاز یک بار دیگر php install.php
   را اجرا کنید.

----------------------------------------------------------------
 گام ۸ — ثبت کرون‌ها (صف و زمان‌بند)
----------------------------------------------------------------
cPanel → Cron Jobs. دو مورد زیر را اضافه کنید (USERNAME را عوض کنید):

هر دقیقه (زمان‌بند Laravel):
  * * * * * cd /home/USERNAME/rezomeh && php artisan schedule:run >> /dev/null 2>&1

هر ۵ دقیقه (پردازش صف database):
  */5 * * * * cd /home/USERNAME/rezomeh && php artisan queue:work --once --sleep=30 >> /dev/null 2>&1

نکته: اگر دستور php پیدا نشد، در Terminal اجرا کنید
  command -v php
و مسیر کامل (مثلاً /usr/local/bin/php) را در کرون بگذارید.

----------------------------------------------------------------
 گام ۹ — چک‌لیست پس از نصب
----------------------------------------------------------------
□ دامنه را در مرورگر باز کنید — سایت باید بالا بیاید
□ /admin (یا آدرس پنل ادمین) را باز و لاگین کنید
□ یک محصول/مطلب چک کنید و یک تصویر آپلود کنید
□ از پنل ادمین خروجی JSON یا سفارش تستی بگیرید
□ فایل database.sql را از سرور حذف کنید (امنیت)
□ فایل install.php را از سرور حذف کنید (امنیت)
□ در .env مطمئن شوید APP_DEBUG=false است

----------------------------------------------------------------
 عیب‌یابی سریع
----------------------------------------------------------------
- صفحه خالی/خطای 500: دسترسی storage و bootstrap/cache را 755 کنید
  و دوباره php install.php بزنید.
- خطای دیتابیس: نام/رمز DB در .env را چک کنید (cPanel نام‌های
  دیتابیس را با پیشوند نام کاربری می‌سازد: username_dbname)
- دارایی‌های CSS/JS 404: document root باید .../public باشد (گام ۲).
- کرون اجرا نمی‌شود: مسیر php را با command -v php بگیرید.
- اگر ترمینال در دسترس نبود: با پشتیبانی هاست تماس بگیرید یا
  پیام بدهید تا راهنمای جایگزین بدون Terminal آماده شود.
